Быстрый старт

Три шага до работающего бота. Клонируйте, настройте .env, запустите.

# Клонируйте репозиторий $ git clone https://github.com/foridorpo-blip/botpulse.git $ cd botpulse $ pip install -r requirements.txt
# Скопируйте пример и заполните токен бота $ cp .env.example .env # .env TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather # AI (опционально — любой провайдер) AI_PROVIDER=gemini AI_API_KEY=ваш_ключ AI_MODEL=gemini-2.0-flash
# Настройте проверки $ cp data/checks.example.json data/checks.json # Отредактируйте data/checks.json под свои сервисы # Запустите бота $ python -m bot.main

Возможности

Четыре типа проверок и AI — всё в одном боте.

VPN-сервисы

Баланс и статус подписок: 3X-UI, Outline, Marzban и другие панели. Токен API — и бот проверит остаток дней и трафика.

Криптокошельки

Баланс BTC, ETH, BSC, TRX по публичному адресу. Без приватных ключей — только чтение через публичные API.

API-сервисы

Баланс API-ключей OpenAI, Gemini, DeepSeek и других провайдеров. Встроенные шаблоны для популярных сервисов.

Универсальный HTTP

Любой HTTP-API запрос с извлечением значения по JSON-пути. Поддержка GET/POST, кастомных заголовков и авторизации.

Команда Что делает
/check_all Запускает все настроенные проверки и показывает сводный отчёт
/check <name> Выполняет одну проверку по имени из конфигурации
/ai <вопрос> Задаёт вопрос AI — с контекстом результатов проверок
/checks Показывает список всех настроенных проверок
/status Статус AI-модуля: провайдер, модель, настроен или нет
/config_example Показывает пример JSON-конфигурации проверок

Частые вопросы

Короткие ответы на основные вопросы.

Как получить токен Telegram-бота?
Напишите @BotFather в Telegram, отправьте /newbot, выберите имя и username. Полученный токен вставьте в .env в поле TELEGRAM_BOT_TOKEN.
Какой API-ключ нужен для AI?
Любой. Укажите AI_PROVIDER (gemini, openai, deepseek, openrouter) и вставьте ключ в AI_API_KEY. Для кастомного провайдера укажите AI_BASE_URL вручную. Поле ключа пустое по умолчанию.
Безопасно ли использовать API-ключи?
Ключи хранятся только в локальном файле .env, который исключён из Git через .gitignore. Никакие ключи не передаются третьим лицам.
Как добавить свою проверку?
Отредактируйте data/checks.json. Добавьте объект с полями: name, check_type (vpn, crypto, api_service, universal), и параметры (url, token, address и т.д.). См. /config_example в боте.
Какие криптовалюты поддерживаются?
BTC (через blockchain.info), ETH (через etherscan.io), BSC (через bscscan.com), TRX (через trongrid.io). Для ETH и BSC нужен бесплатный API-ключ соответствующего эксплорера.
